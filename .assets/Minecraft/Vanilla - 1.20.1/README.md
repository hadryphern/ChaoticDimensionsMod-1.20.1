# Minecraft Vanilla 1.20.1 — referência local

Extraído do `minecraft-client.jar` local usado pelo ambiente Fabric. Os caminhos, nomes, dimensões e pixels são os originais do Minecraft 1.20.1.

- Blocos: `assets/minecraft/textures/block/`
- Itens: `assets/minecraft/textures/item/`
- Modelos: `assets/minecraft/models/`
- Blockstates: `assets/minecraft/blockstates/`
- Textos: `assets/minecraft/lang/en_us.json`
- Sons: `assets/minecraft/sounds/`
- Catálogo de texturas, dimensões e SHA-256: `texture-catalog.csv`

Uso: referência local para desenvolvimento. Esta pasta é ignorada pelo Git e não deve ser redistribuída com o mod.
